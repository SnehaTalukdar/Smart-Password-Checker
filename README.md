# Smart Password Strength Checker

Simple web application to check the strength of a password based on its length, uppercase letters, lowercase letters, numbers and special characters.

## Features
Check the strength of the password instantly
Display weak, medium or strong status
Show/hide password
View password requirements

## Technologies
HTML
CSS
JavaScript

## Running the Application

1. Download/Clone the repo.
2. Open index.html in your browser
3. Enter a sample password.

## Disclaimer
This project is purely for educational purposes. Please do not enter any real or sensitive passwords.
